# Dossier `brand/`

Tes fichiers de marque, ignorés par git (seuls ce README, `EXEMPLE.md` et `skills/` sont versionnés) :

- **Document de référence** : `MARQUE.md` par défaut (ou le `brandDoc` de ton espace dans `workspaces.json`). Pars de [`EXEMPLE.md`](EXEMPLE.md).
- **Icône de l'app de bureau** (optionnel) : `app-icon.png`, utilisée par `desktop/make-app.sh`.
- **Skills par réseau** : `skills/`, guides open source envoyés à l'assistant (sources et licences dans [`skills/README.md`](skills/README.md)).
